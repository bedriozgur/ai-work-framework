# Review and Handoff Pattern

Use when work spans agents, models, machines, or sessions.

## Review
1. Inspect the saved artifact, not only the producer's summary.
2. Re-run deterministic checks where available.
3. Verify required sources and freshness.
4. Challenge material assumptions and unsupported conclusions.
5. Correct failures and re-run affected checks.
6. Keep unresolved uncertainty visible.

## Handoff
Use the handoff/return fields in `../GOVERNANCE.md` and the lifecycle requirements in `../AGENT-OPERATING-PROTOCOL.md`. Do not define a pattern-specific field list.

A handoff is a navigation aid, not a substitute for inspecting authoritative project state.
